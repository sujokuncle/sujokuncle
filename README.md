## Projects

### 🤟 Indian Sign Language Recognition · Edge AI
> Real-time, offline ISL alphabet recognition — no cloud, no latency, just inference.

- **196-dimensional** hand landmark features extracted via MediaPipe
- **26 gesture classes** with a quantized Residual MLP
- **INT8 TFLite model** — ~200 KB, running at **8ms inference / 25–30 FPS** on Raspberry Pi 4
- Arduino Nano 33 BLE Sense IMU + BLE sensor fusion to disambiguate motion-dependent gestures (J/Z)
- **87.8% accuracy** on real-world gesture sequences

`MediaPipe` `TensorFlow/Keras` `TFLite INT8` `Arduino BLE` `Raspberry Pi 4` `Python`

---

### 🚗 JetRacer Autonomous Navigation · *In Development*
> SLAM + LiDAR based navigation for confined spaces and heavy earth movers.

- WaveShare JetRacer platform with custom autonomy stack
- Targeting zero-downtime operations in **fog, rain, and low-visibility conditions**
- SLAM-based mapping for GPS-denied confined environments
- Exploring deployment on heavy earth moving vehicles to reduce operational downtime

`SLAM` `LiDAR` `ROS` `WaveShare JetRacer` `Python` `C++`
